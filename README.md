# Hadees Tap

## How do I install these formulae?

`brew install hadees/tap/<formula>`

Or `brew tap hadees/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "hadees/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
